
# Application de Gestion des Bons de Sortie

## Description du projet

Application web développée avec **Django, HTML, CSS et JavaScript** permettant de gérer et de suivre les bons de sortie du matériel au sein d'une usine.

L'application assure la traçabilité des équipements sortis du site, la validation hiérarchique des demandes par les responsables de l'usine et le suivi des matériels non retournés.

## Fonctionnalités principales

- **Gestion des bons de sortie :** création, consultation, modification et suivi des bons de sortie du matériel.
- **Validation hiérarchique :** mise en place d'un circuit de validation selon la hiérarchie des responsables de l'usine.
- **Gestion des responsables :** attribution des rôles et des niveaux de validation selon les responsabilités.
- **Suivi des équipements :** suivi des matériels sortis, retournés et en attente de retour.
- **Notifications par e-mail :** envoi automatique d'e-mails pour signaler les matériels non retournés dans les délais prévus.
- **Traçabilité :** conservation de l'historique des demandes, validations, sorties et retours de matériel.

## Technologies utilisées

| Technologie | Utilisation |
|---|---|
| Python | Langage de programmation |
| Django | Framework Backend |
| HTML5 | Structure des pages |
| CSS3 | Mise en forme et design |
| JavaScript | Interactivité côté client |
| SQLite / MySQL | Gestion de la base de données |
| SMTP | Envoi des notifications par e-mail |

## Objectifs du projet

- Digitaliser le processus de gestion des bons de sortie.
- Assurer un circuit de validation structuré et hiérarchique.
- Améliorer le suivi et la traçabilité des équipements.
- Réduire les pertes de matériel grâce aux alertes automatiques.
- Faciliter la communication entre les responsables de l'usine.
